功能

一个播放器，替你听懂全世界的视频

日剧、韩综、美剧、纪录片、网课、家庭录像……没有字幕的视频，打开就有。

⚡

边播边译，开头几秒就出字幕

本地文件可以提前读取后面的音频，所以不用质量差的"实时流式识别"：每次听 40 秒、在静音处断句、马上翻译，在播放位置前保持约 3 分钟缓冲。进度条上灰蓝色 = 已识别，绿色 = 已翻译，一目了然。

🚀

秒播，字幕随后赶上

打开视频立刻播放，不用等 AI；识别引擎在后台加载，先识别画面附近的一小段，第一句字幕约 1 秒就出来。

🎨

字幕想怎么显示就怎么显示

字体、字号、颜色、描边、阴影、半透明背景框，4 个模板一键套用；字幕可以上下移动，避开片子里的硬字幕。

🔒

全部在你的电脑上完成

语音识别（whisper.cpp）和翻译（腾讯混元 Hy-MT2）都跑在本机。视频不上传，没有账号，断网也能用。

🌏

十几种语言 → 中 / 英

只听音频自动判断语言。英、日、韩、法、德、西、俄、泰、越……可以设定哪些语言要翻译、翻译成简体 / 繁体 / 英文。

🎚️

双语 / 译文 / 原文，一键切换

译文下面带一行小字原文，学外语也好用。字号、显示隐藏、字幕旋转都能单独调，长句自动换行。

识别 + 翻译

常见问题

你可能想问

真的免费吗？有什么限制？

个人使用完全免费，没有广告、没有账号、没有时长限制。禁止任何商业用途（包括在公司内部使用、用于商业服务、转售或打包分发）。

没有显卡能用吗？

可以。程序启动时会检测硬件并推荐配置：8 核以上 CPU 边播边译基本流畅；较弱的 CPU 建议先用"整片生成"提前做好字幕。

会上传我的视频吗？

不会。默认的识别和翻译都在本机完成。只有你主动选择 DeepSeek 等在线翻译接口时，才会把字幕文字（不是视频和声音）发给对应的服务。

翻译质量怎么样？

内置的腾讯混元 Hy-MT2 是专门的翻译模型，日常对白通顺；追求更好的人名、俚语和长句，可以换成混元 7B 或 DeepSeek API（一部电影大约几毛钱）。

生成的字幕能给别的播放器用吗？

可以。字幕以 影片名.语言.srt 保存在视频旁边，PotPlayer、VLC、mpv、Emby、Plex 都能直接加载；也可以设为隐藏文件，文件夹更整洁。

怎么升级到新版本？

主菜单 →「关于 / 检查更新…」→「检查更新」，有新版本时点「下载并安装」即可：安装包会自动校验，装好后程序自动重新打开。也可以随时从本页下载最新安装包，直接覆盖安装。

「边播边译」改名了吗？

是的，从 1.5.2 起中文名改为「快译全能播放器」，英文名仍是 Navo Player。从 1.5.1 升级时直接安装新版，设置、播放记录、截图和已下载的模型会自动迁移；之后可以在 Windows「设置 → 应用」里卸载旧的「边播边译」。
